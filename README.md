# MINI SISTEMA OPERATIVO
## Descripción
Este proyecto consiste en el desarrollo de un mini sistema operativo educativo con interfaz gráfica, que simula  4 funciones básicas de un sistema operativo real según los requerimientos. Estos cuatro procesos son:
- Exploración de archivos
- Gestión de procesos
- Shell Educativa (Ejecución de comandos)
- Información del sistema
