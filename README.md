# MINI SISTEMA OPERATIVO

## Descripción

Este proyecto es un mini sistema operativo educativo con interfaz gráfica que simula 4 funciones básicas de un sistema operativo real:

- Explorador de archivos
- Gestión de procesos
- Shell educativa (ejecución de comandos)
- Información del sistema

## Tecnologías usadas

- Lenguaje: Python
- Interfaz gráfica: Tkinter

## Estructura del proyecto

```text
PROYECTO_FINAL_SISTEMAS_OPERATIVOS/
├── main.py
├── modulos/
│   ├── explorador.py
│   ├── procesos.py
│   ├── shel.py
│   └── sistema.py
└── README.md
```

### Descripción de archivos

- `main.py` - Punto de entrada de la aplicación.
- `modulos/explorador.py` - Módulo para el explorador de archivos.
- `modulos/procesos.py` - Módulo para la gestión de procesos.
- `modulos/shel.py` - Módulo para la shell educativa.
- `modulos/sistema.py` - Módulo para mostrar información del sistema.
- `README.md` - Documentación del proyecto.
